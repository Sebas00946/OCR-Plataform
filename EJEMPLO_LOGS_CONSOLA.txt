================================================================================
RESUMEN DE LOGS EN ARCHIVOS
================================================================================

Archivo: logs/api_requests.log
-------------------------------
Contiene TODAS las peticiones HTTP con:
- Timestamp completo
- Endpoint y método
- Status code
- Duración en milisegundos
- IP del cliente
- Datos completos en JSON


Archivo: logs/processed_files.log
----------------------------------
Contiene TODOS los archivos procesados con:
- ID de factura
- Nombres de archivos XML y PDF
- Sucursal detectada
- Unidad funcional detectada
- Éxito o fallo del procesamiento
- ID del historial


Archivo: logs/statistics.log
-----------------------------
Contiene TODAS las consultas de estadísticas con:
- Total de clasificaciones
- Precisión del sistema
- Confianza promedio por tipo
